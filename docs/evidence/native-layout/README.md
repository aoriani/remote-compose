# Native layout evidence

See ../../NATIVE_LAYOUT_FIX.md. Before images are the actual original native screens;
after images use the final responsive retail publication19. Contact sheets uniformly
scale thumbnails for reading; all source PNGs are retained without aspect normalization.

proof.json records the successful combined four-configuration suite, three shared binary
identities, actual viewport/root dimensions, exact edge RGB, circle diameters and real
scroll changes. serverOnlyRecords records the later hero-clearance adjustment on unchanged
installed apps, including XCTest test-without-building. Client binary SHA values match.

Calibration images show bitmap/vector/nested layout and large text cases. Native test
transcripts have machine-specific home paths normalized. The source fixtures are
samples/viewport-layout*.json and samples/retail-home.json. Reproduce with
scripts/verify-native-layout.sh after the documented tool/device/backend setup.

Old390×844 native pixel goldens do not establish container correctness. The updated
capture tools retain actual native pixels and reject incompatible dimensions.
