# Candidate fixtures

`minimal-canvas.json` is a **syntax-checked candidate**, based on upstream creation
parser structures. It has not been compiled, decoded, or rendered. Its header profile,
modifier form, and paint syntax must be checked at the selected AndroidX commit.

Promote it to a verified fixture only with evidence of JVM compilation, metadata/opcode
inspection, and genuine browser rendering. Later capture the exact binary SHA-256 on
Android and iOS to establish that all players consume identical bytes.
